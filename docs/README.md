# Documentation map

> **The specification lives in Notion, and Notion is the source of truth.**
> This directory carries a summary plus the day-to-day project state. When the
> two disagree, Notion wins — and the disagreement is a bug worth reporting.

**Notion (canonical spec):** https://www.notion.so/3e29cda8bea1809e9077d080a350d218

## What is where

| Where | What it holds |
| --- | --- |
| Notion "Lita" | Product spec, decision table, risks, open questions |
| Notion "Lita — 技術仕様" | Codex invocation, Slack PKCE flow, data model, Voice schema |
| Notion "Lita — 引き継ぎメモ" | Cross-session progress and the next move |
| `docs/pm/state.md` | Where the project is right now |
| `docs/pm/decisions.md` | Decision log — issue, decision, rationale, date |
| `docs/pm/backlog.md` | What is not done yet, in priority order |

| `.claude/agents/lita-pm.md` | The PM agent's role definition |

## A note on language

Project-facing documentation (README, code comments, issues) is written in
English so that contributors can read it. The PM working notes under `docs/pm/`
are written in Japanese, because they mirror the Japanese-language spec in
Notion and are maintained by the project owner.
