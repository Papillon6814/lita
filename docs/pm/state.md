## いま効いている制約

PoC で分かったことです。詳細は [`2026-09-22-codex-poc.md`](2026-09-22-codex-poc.md)。

1. **トークンストリーミングがない。** `codex exec` のイベントは4種類だけで、答えは最後に一括で届きます。
2. **生成が遅い。** Voice 抽出 45.6秒、ポスト生成 26.6秒。1と合わせると約30秒の無音になります。
3. **JSON Schema には `description` が要る。** 型だけではモデルに意図が伝わりません。
