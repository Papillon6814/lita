# 検証記録: Voice スキーマの確定（B-04 / Issue #7）

- **実施日**: 2026-09-22
- **方法**: 24件の発言から Voice を1つ抽出し、その**部分集合4通り**から同じブリーフで X ポストを**3回ずつ**生成して比較
- **再現方法**: `cargo run -p lita-codex --bin schema`
- **確度**: 1コーパス・1ブリーフ・推論量 low のみ。n=3。傾向は明瞭だが、母数は小さい【確度：中】

## 結論

**Voice には引用（`representative_excerpts`）を保存するが、生成には渡さない。** 生成が受け取るのは構造化フィールドだけです。

理由は、引用を渡すと**構造化フィールドが無視され、しかも過去の投稿の文がそのまま出てくる**からです。

## 実測

同じ Voice の4つの部分集合から、同じブリーフで3回ずつ生成した平均です。

| 渡した内容 | 文字数 | 所要 | 特徴語の使用（10語中） | `uses_emoji` の遵守 |
| --- | --- | --- | --- | --- |
| 全部（引用込み） | 1270 | 9.2秒 | 1.3 | **0/3** |
| **構造化フィールドのみ** | 786 | 8.1秒 | **2.7** | 2/3 |
| 引用のみ | 486 | 6.9秒 | 0.7 | **0/3** |
| 最小（一人称・トーン・文末・絵文字） | 317 | 10.1秒 | 0.3 | 3/3 |

### 見つかったこと

**1. 引用が構造化フィールドを上書きする。** プロファイルは `uses_emoji: true` なのに、引用を含めた2条件はどちらも 0/3 で絵文字を出しませんでした。引用した3文にたまたま絵文字がなかったためです。**具体例は抽象的な記述に勝ちます。** ここではそれが裏目に出ます。

**2. 引用は文をそのまま持ってくる。** 「引用のみ」は3回とも「これ1つだけ覚えて帰ってください」を**サンプルから借用**しました。「全部」でも1回出ています。発信ツールで新しい投稿が過去の投稿をなぞるのは事故です。

**3. `preferred_words` が一番効く。** 構造化フィールドのみの条件で「僕ら」「思ってます」「反応」「個人的には」が自然に出ました。人の文章らしさを作っているのは、この語彙リストです。

**4. 最小構成では個性が薄い。** 絵文字は守るが、「皆さん」のような無難な呼びかけになり、特徴語がほぼ出ません（0.3）。

### 待ち時間について（前回の主張を修正）

前回「プロンプトの大きさが待ち時間に直結する」と書きましたが、**推論量 low ではこの範囲（317〜1270文字）で相関がありませんでした**（6.9〜10.1秒、順不同）。前回の 10.8秒→26秒 の差は推論量 medium での値で、大きなプロンプトが推論トークンを増やしたのが原因です。**プロンプトの大きさは推論が有効なときだけ効きます。** 速度重視モードでは気にしなくてよい、が正しい言い方でした。

## 確定したスキーマ

コードは `crates/lita-codex/src/voice.rs`。全フィールドに `description` があり、ユニットテストがそれを検証しています。

| フィールド | 型 | 生成に渡すか | 補足 |
| --- | --- | --- | --- |
| `language` | string | ○ | BCP-47。今回追加。生成プロンプトの「日本語で書け」をハードコードしないため |
| `first_person` | string | ○ | 1語。避けているなら空文字 |
| `formality` | string | ○ | |
| `tone` | string[] | ○ | 3〜6語 |
| `sentence_endings` | string[] | ○ | 頻度順 |
| `avg_sentence_length_chars` | integer | ○ | |
| `preferred_words` | string[] | ○ | **最も効く** |
| `avoided_words` | string[] | ○ | |
| `opens_with` | string | ○ | |
| `closes_with` | string | ○ | |
| `uses_emoji` | boolean | ○ | |
| `representative_excerpts` | {excerpt, why}[] | **✕** | 本人が「何から作られたか」を読むために保存。生成には渡さない |

`VoiceProfile::generation_view()` が「生成に渡す形」を返し、テストが `representative_excerpts` を含まないことを保証しています。

## 残る不確かさ

- 1コーパス・1ブリーフでの結果。長文（note 記事）や別の書き手で同じ傾向かは未検証
- `avg_sentence_length_chars` / `opens_with` / `closes_with` が個別に効いているかは分離して測っていない。害がないので残した
- `preferred_words` に「ので」「数字」のような汎用語が混ざる。抽出プロンプトで「その人らしい語」に絞る指示を強めた
