# 新しい社内勉強会を始めた理由

私たちが新しい社内勉強会を始めたのは、仕事の中で生まれる疑問を、みんなで考える時間を持ちたいからです。日々の業務では、目の前の課題に向き合うことが中心になります。その中で気になったことを持ち寄り、少し立ち止まって学べる場も大切にしたいと考えています。

今回は、勉強会を始めた背景と、私たちがこの場で大切にしたいことをお伝えします。採用に関心を持ってくださる方や、仕事をご一緒する取引先の方に、私たちの働き方を知っていただくきっかけになればと思います。

## 仕事の中にある疑問を、そのままにしない

仕事を進めていると、手順は分かっていても、その背景まで説明するのは難しいことがあります。いつもの方法を選びながら、ほかのやり方もあるのではないかと考えることもあるでしょう。

そうした疑問は、すぐに答えが必要なものばかりではありません。だからこそ、日々の仕事の中では、後で考えようと置いてしまいやすいものだと思います。私たちは、その小さな引っかかりにも、学びの入り口があると考えています。

例えば、ある進め方がうまくいったとき、結果だけを見れば、その仕事は完了したと言えるかもしれません。ただ、なぜうまくいったのかを考えると、次の仕事にも生かせる気づきが見つかるのではないでしょうか。反対に、迷ったことや思うように進まなかったことにも、振り返る意味があります。

一人で考える時間も必要です。そのうえで、誰かに話すことで、自分が何を分かっていて、どこで迷っているのかが整理されることもあると思います。聞いた人の問いかけが、別の見方につながることも期待しています。

社内勉強会を、そうした対話のきっかけにしたいと考えています。普段の仕事で感じた疑問を言葉にして、みんなで考える。その時間を持つことが、今回の取り組みの出発点です。

## 分からないことも持ち寄れる場にする

勉強会という言葉には、詳しい人が準備をして、ほかの人に教える場という印象があるかもしれません。もちろん、得意なことや経験を共有する時間には価値があります。同時に、私たちは、まだ答えの出ていないことも話せる場にしたいと思っています。

何を調べればよいか分からない。説明を読んでも、仕事のどこで使うのかが見えない。そうした途中の状態を共有できれば、参加する人も自分の疑問を重ねやすくなるのではないでしょうか。

話す側にも、きれいな結論を求めすぎないようにしたいと考えています。試してみたい方法や、考えがまとまっていない部分にも、話し合う余地があります。分からないと言えることを、学ぶために必要な姿勢として大切にしたいです。

聞く側の姿勢も、同じように大事だと思います。自分にはなじみのある話でも、相手は別の前提から考えているかもしれません。すぐに答えを伝える前に、どこで迷ったのか、何を知りたいのかを聞く。そのやり取りを通じて、話す側も聞く側も理解を深められる場を目指します。

また、学ぶことが日々の仕事に無理を重ねる理由になっては、続けにくくなります。準備にどこまで時間をかけるか、どのくらいの内容なら持ち寄りやすいか。こうした点も、参加する人の声を聞きながら考えていきたいです。

最初から形を決めすぎず、必要に応じて少しずつ見直す。勉強会そのものの進め方についても、私たちは学んでいくつもりです。

## 学んだことを、次の仕事につなげる

勉強会で聞いた話が、そのまま目の前の仕事に使えるとは限りません。学んだ内容を理解することと、自分たちの状況に合う方法を選ぶことには、それぞれ考える時間が必要です。

だからこそ、聞いて終わりにせず、日々の仕事に戻ったときにも思い返せる場にしたいと考えています。次に似た課題に出会ったとき、別の方法を検討してみる。判断に迷ったとき、詳しい人に相談してみる。そのような行動につながれば、学ぶ時間の意味を感じられると思います。

採用に関心を持ってくださる方には、私たちが、入社時点の知識だけでその後の働き方が決まるとは考えていないことをお伝えしたいです。経験や得意なことを持ち寄りながら、分からないことを一緒に考える。そうした関わりを、日々の仕事の中でも大切にしていきたいと思っています。

取引先の方との仕事でも、学び続ける姿勢を生かしたいと考えています。ご相談の背景を理解しようとすること。慣れた方法でも、今回の目的に合っているかを確かめること。勉強会で育てたい問いかける習慣は、仕事に向き合う姿勢にもつながるはずです。

新しい勉強会を始めたことで、学びの場が完成したとは考えていません。続ける中で、話しやすさや仕事へのつながりを確かめ、少しずつ整えていきたいと思います。私たち自身も学びながら、この場を育てていきます。

私たちとお話しする機会があれば、ぜひ、仕事の中で今学んでみたいことを聞かせてください。
