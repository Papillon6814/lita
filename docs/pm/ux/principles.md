# Lita の UI/UX 原則（正）

保守責任: `lita-ux` エージェント。変えるときは日付と理由を末尾の改訂欄に残す。
出所: 2026-09-22 の UX 批評（`../2026-09-22-ux-rereview.md`）、2026-09-23 の v0.2 レビューと文体レビュー（`../2026-09-23-v02-review.md`、`../2026-09-23-voice-ux-review.md`）、決定 D-44・D-46・D-50・D-52〜D-57。

1. **一つの概念に一つの名前。** 画面の語は「文体」「記事」「学習ソース」。Voice・プロファイル・ソースは出さない。
2. **正常時は静か。** 数字・内部制約・進捗の演出は、困るときだけ出す。
3. **主ボタンは画面に一つ。** 二次操作は「…」か薄いリンク。破壊的操作は主ボタンの隣に置かない。
4. **任意は任意に見せる。** 選ばなくても進めるものは、空欄でも先に進めることが 3 秒で分かる。必須は入力の場所と数で示す（「※必須」の札は使わない）。
5. **その場で直す。** モーダルより行内編集。戻る道を常に一つ残す。
6. **想定は 1〜2 本、数件。** 一覧が 1 件なら一覧を出さない。空の状態は次の一手を 1 つだけ示す。
7. **エラーは平易な一文＋次の行動。** コードや生の文言を出さない。
8. **見た目はトークンから。** ライトのみ、紙色 `#fffdf9`、インク `#2b2a27`、ミント `#1d7f70`（文字・塗り）／`#41c9b4`（点）、角丸 8（操作部品）／12（入れ物）、書体 Zen Kaku Gothic New。新しい色や角丸を足さない。
9. **文言は です・ます で短く。** 主語は「あなたの文章は」。動詞で終える。英語は同じ意味で同じ数だけ用意する。
10. **手数で測る。** 変更の前後でクリック数と判断の数を数え、増えるなら理由を書く。
