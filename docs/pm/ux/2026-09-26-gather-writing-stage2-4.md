## 1．結論

**雲の箱をいつも置き、雲が出ないときは箱の中に「一文＋文章を足す」を 1 つだけ置きます。** 押すと、箱の場所に既存の 2 つの器（貼る・つなぐ）がそのまま開きます。足すと器は閉じて箱に戻り、自動で言葉を拾います。

**段 4 は新しい入口を作りません。** 貼る欄が「会話のコピー」を見分けると、欄の中身を**あなたの発言の本文だけ**に置き換え、「会話から、〇〇 の発言だけを残します。 選び直す」の一文を出します。道具の名前（Slack・Teams・LINE…）は画面のどこにも出しません。名前が 2 人以上で、覚えた名前が無いときだけ「あなたはどれですか」と名前を並べます。

案は 1 つに絞りました（迷う箇所が無かったため）。

## 3．案

### 3.1 段 2: 雲の箱に一手を置き、その場で器を開く

```
①文章 0 本                                ②「文章を足す」を押した
┌ よく書いている言葉 ──────────────┐      文章を足す                         閉じる
│                                  │      足した文章は、文体「〇〇」の元にした文章にも入ります。
│ あなたの文章を足すと、よく書いて │      ┌ 自分の文章を貼る  チャットの会話も…┐
│ いる言葉がここに並びます。       │      │ [                                ] │
│                     文章を足す   │      │ 足す          テキストファイルを選ぶ│
└──────────────────────────────────┘      └────────────────────────────────────┘
                          [題を出す]                 どちらも入れられます。
                                           ┌ 書いた場所からつなぐ ──────────────┐
③足した直後 → 雲の箱に戻って拾う          │ ▸ note / ▸ Medium / ▸ X            │
┌ よく書いている言葉 ──────────────┐      └────────────────────────────────────┘
│   ◌ 言葉を拾っています… やめる    │                                [題を出す]
└──────────────────────────────────┘
```

- **雲の箱はいつも置きます**（文体があれば）。空でも箱が残るので、言葉がどこに出るかが最初から分かり、拾っている行・一手・雲が同じ場所で入れ替わります。見出し行と「題を出す」の位置は動きません（原則 2）。「題を出す」は雲があるときと同じ右下に置きます（いまの `stack alone` は使わない）。
- 箱の中の一手は、状態で 3 つのどれか 1 つだけです（原則 6、段 1 レビュー 4 節の 2）。

| 状態 | 箱の中 | 一手 |
| --- | --- | --- |
| A 元にした文章が 0 本 | 「あなたの文章を足すと、よく書いている言葉がここに並びます。」 | 文章を足す |
| B 文章はあるが、拾えた言葉が 3 つ未満 | 「拾えた言葉がまだ少なく、並べられません。」 | 文章を足す |
| C 文章はあるが雲が無く、拾っていない（最初の拾いを「やめる」で止めた） | 「言葉を拾うのをやめました。」 | 拾い直す |
| 拾っている | いまの「言葉を拾っています… やめる」 | （一手は出さない） |
| 拾うのに失敗 | いまの「言葉を拾えませんでした。…」＋「拾い直す」 | （同） |

- 「文章を足す」を押すと、**雲の箱の場所に**見出し「文章を足す」＋「閉じる」の区画が開きます（編集方針をその場で開くのと同じ組み方）。中身は上から「足した文章は、文体「〇〇」の元にした文章にも入ります。」の一文、`PasteBox`、「どちらも入れられます。」、つなぐ器（`SourceBox`）。**別の貼る欄は作りません**。
- 「足す」（器の中の小さなボタン）と「題を出す」（主ボタン）の間には、つなぐ器が挟まり、並んで見えません（`add-2.png`）。
- **足したら器を閉じて箱に戻し、すぐ言葉を拾います。** note などをつないで取り込み終えたときも同じです。拾った結果が 3 語に届かなければ B の一文に戻り、同じ一手でもう一度足せます。
- 開いた区画と編集方針は同時に開きません（片方を開くともう片方は閉じる）。区画が開いたまま「題を出す」を押すと、編集方針と同じく区画を閉じます（貼りかけの文字は捨てる。保存前なので失うものは貼り直せる）。
- 題が出たあとは、雲が無ければ箱ごと出しません（いまの「出し直す」の見出し行のまま）。

### 3.2 段 4: 貼る欄が会話を見分ける（道具の名前は出さない）

```
⑦名前が 1 人（自分に絞って検索した結果など）      ⑧名前が 2 人以上・覚えた名前なし
┌ 自分の文章を貼る  チャットの会話も、そのまま…┐  ┌ 自分の文章を貼る  …──────────────┐
│ [来週の採用面談、評価シートを…             ] │  │ ┌ 会話を貼りました。あなたはどれですか。┐│
│ [資金繰り表は週次に切り替えました…         ] │  │ │ [久野 太郎] [佐藤 花子] [Mika] この中にいない││
│ 会話から、久野 太郎 の発言だけを残します。 選び直す│ └──────────────────────────────┘│
│ 足す                   テキストファイルを選ぶ│  │ 足す(押せない)                 やめる│
└──────────────────────────────────────────────┘  └──────────────────────────────────┘
```

- **入口は増やしません。** 貼る欄の見出しの右に、X の行の説明と同じ重さで 1 文だけ置きます:「チャットの会話も、そのまま貼れます。あなたの発言だけを残します。」。検索の記法も道具の名前も出しません（どの道具でも同じ文で通じるように。記法は道具ごとに違う）。ふだんの説明（プレースホルダ「気に入っている文章を、まとめて貼れます。」）とは置き場所が違うので競いません。
- **貼った瞬間に欄の中身を置き換えます。** 名前・時刻・画面の文字・他人の発言は欄に一度も入りません。欄には本人の発言の本文だけが空行区切りで並び、そのまま直せます（要らない発言は欄で消せばよく、1 件ずつ外す一覧は作らない）。
- 欄の下の一文（いまの「n 本として読みます」の場所・重さ。警告の色にしない）は状態で替わります:

| 状態 | 欄の中 | 一文 | 「足す」 |
| --- | --- | --- | --- |
| 名前が 1 人、または覚えた名前が会話にいる | 本人の発言の本文 | 会話から、**〇〇** の発言だけを残します。 選び直す | 押せる |
| 前に入れた発言と一部重なる | 重なりを除いた本文 | 会話から、**〇〇** の発言のうち、まだ入っていないものを残します。 選び直す | 押せる |
| 名前が 2 人以上で、覚えた名前がいない | 欄の代わりに白い札「会話を貼りました。あなたはどれですか。」と名前のボタン＋「この中にいない」 | ― | 押せない。右に「やめる」 |
| 本人の発言が 1 つも残らない（「この中にいない」を含む） | 空 | この会話には、あなたの発言が見つかりませんでした。自分の発言を含めて貼り直してください。 | 押せない |
| すべて前に入れた発言と同じ | 空 | この発言は、どれももう入っています。 | 押せない |
| 会話だと分からない | 貼ったまま | いまの「n 本として読みます。 1 本にまとめる」 | いまのまま |

- 「選び直す」は ⑧ の札を出します（名前は同じ会話から）。名前を選ぶと ⑦ の姿になります。
- **名前はこの端末に覚えます**（道具ごとに表示名が違うので、1 つではなく**名前の集まり**として覚える）。「足す」を押したときに、そのとき選ばれていた名前を足します。名前が 1 人だけの会話では聞かずに進め、一文に名前が出るので違えば「選び直す」で気づけます。
- 足すと **1 回の貼り付けが 1 本**として入り、「元にした文章」の行の名前は **「会話から・9月26日」**（`talk-12.png`）。ふつうに貼った文章の行は今までどおり 1 行目です。
- 「書く題を決める」から開いた区画では、足したあと 3.1 と同じく閉じて自動で拾います。文体の入口と文体ページでは、いまの貼り付けと同じく一覧に 1 行増えるだけです。

### 7.2 決めごと（迷いそうなところ）

- **足す先の文体**: `TopicPicker` が既に持つ `voiceId`（直近の記事の文体、1 つならそれ、D-55）。`voiceId` が空（文体 2 つ以上・記事 0）のときは `listVoices` の先頭を使い、`add.where` にその名前を出す。
- **`PasteBox` をこの画面で使うとき**: `pieces={[]}`（一覧は出さない。足せば区画は閉じる）、`total={0}`（「4 本ほどあると…」は文体の読み取りの話なので、この画面では出さない）、`onEdit`・`onMerge` なし。
- **`SourceBox` をこの画面で使うとき**: `connected` はその文体のつながり、`onRemove`・`onRefresh` なし、`known` はその文体の `origin`。
- **会話を見分けるのは貼ったとき**（`onPaste`）。欄が空のとき、または欄が既に会話の姿のときだけ見分ける。後者は後ろに足し、重なりを除く。欄に普通の文章があるところへ貼ったら普通の貼り付け。
- **元の中身の持ち方**: 名前を選ぶまでと「選び直す」のために、元の中身は `useRef` にだけ持つ。欄・`localStorage`・サーバには入れない。足した・欄を空にした・区画を閉じた・部品が消えたときに捨てる（必須 22）。
- **覚える名前**: `localStorage` の 1 キー（例 `lita.talk.me`）に名前の配列。サーバに送らない。会話の名前にこの中のものがいればそれを本人とし、聞かない。
- **重なり**: 発言の本文を空白を詰めて比べる。欄に出す前に除く（見えているものがそのまま入る）。
- **会話のときの 1 本の本文**: 発言を空行でつないだもの。発言の中の空行は 1 つの改行に詰める（あとで発言に分け直せるように）。
- **フォーカス**: 名前の札が出たら最初の名前へ。一文は `role="status"`。
- **.txt を落としたとき**は今までどおり（会話の読み手に通すのは任意。LINE の書き出しは .txt なので、後で同じ関数に通せる）。

## 9．本人に決めてほしい論点

1. **雲が出たあとも「文章を足す」を残しますか。** いまの要件では、一手は雲が出ないときだけです。会話は何度でも貼るものなので、雲が出た後は文体ページまで行かないと足せません。残すなら、雲の見出しの右に「拾い直す」と並べて薄いリンクで置きます（足せば自動で拾うので、「拾い直す」を押すことはほぼ無くなります）。**推奨は残す**。案 C の組み立て（入力欄 0・主ボタン 1）は崩れません。
2. **会話の見本を 2 つください。** いちばん貼りそうな道具を 2 つ（例: Slack とメール、Slack と LINE）選び、自分の発言を含む会話を数件コピーして手元のテキストファイルに保存し、lita-dev に渡してください（Issue には貼らない、commit しない）。画面は道具を問わない形にしましたが、見分けの精度は見本で決まります。見本の無い道具は「分からなかった」（今の貼り付け）に戻るだけで、壊れはしません。

## 10．残る懸念

- 見分けを外したとき（⑪）、名前や時刻が本文に混ざったまま入りえます。欄の中身で見えるので本人は気づけますが、見本が届くまで精度は測れません。
- 名前 1 人の会話を聞かずに進めるので、他人の発言だけを貼ると他人の文として入りえます。一文に名前が出るので、そこで気づく前提です。
