## キーボードと読み上げ

- 10 題は `<label>` と `<input type="checkbox">` です。Tab で行から行へ、Space で選べます。提案を出す → 3 題選ぶ → 積む → 1 本やめる、まで Tab と Space と Enter だけで届きます。

- 状態の印はバッジの文字そのものが「書いています」「順番待ち」「書けませんでした」なので、色に頼らずに読めます。

## 残っていること

- 動きを伴う 3 つ（別の記事を編集しながら進む／やめる・止める／閉じて開き直すと続く）は静的 HTML では撮れません。実装後にモックを動かして撮ります。
