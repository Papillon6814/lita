## 2. 案（1 案）

つないでいない行を「畳んだ入口」にする。文体ページの「▸ 詳細を見る」と同じ型で、一行目に名前と短い説明だけを置き、押すと入力欄がその場に開いてフォーカスが移る。

```
空の状態（intake）                           1 つつないだ後（intake-loaded）
┌────────────────────────────────────┐        ┌────────────────────────────────────┐
│ ▸ note    公開記事を取り込みます。…  │        │ ✓  note・kuno 10 件            外す │
│ ▸ Medium  Medium は直近 10 件…      │        │ ▸ Medium  Medium は直近 10 件…      │
│ ▸ X       X の設定からアーカイブを… │        │ ▸ X       X の設定からアーカイブを… │
│   手作業  自分で書く・貼る / ファイル │        │   手作業  自分で書く・貼る / ファイル │
└────────────────────────────────────┘        └────────────────────────────────────┘

▸ note を押すと（intake-open）
│ ▾ note   [note のアカウント名 または URL   ] つなぐ │   ← 入力欄にフォーカス
│          公開記事を取り込みます。有料記事は含みません。   │
```

- **重さの 3 段**: つないだ行 = ✓ ＋ ミントの太字（現状のまま）。軽い行 = 名前は `--mute` の中字、説明は 0.82rem、行の高さを 12px → 9px 詰める、入力欄なし。手作業 = 最後、名前も 2 本のリンクも `--mute`（ホバーでミント）。色・角丸は既存トークンのみ
- **開き方**: 軽い行全体を `<button aria-expanded>`（`aria-controls` で入力欄を指す）にする。押すと同じ行が `form` に変わり、名前が開閉ボタン（`▾`）として残る。`input` は `autoFocus`、X は「tweets.js を選ぶ」ボタンにフォーカス。Esc または名前を押すと閉じ、フォーカスは行に戻る
- **開いたままの行**: 取得中・失敗・「新しい文章はありませんでした」の間は開いたまま置く（必須 8）。つながったら閉じてつないだ行に変わる
- **リード文**: `voice.intake.more` を「あとから足したり外したりできます。」に差し替え、`voice.intake.leadEmpty` に「気に入っている文章のある場所を、どれか一つつなぐだけで足ります。」を入れる。1 つつないだ後は「文体は…書き方です。あとから足したり外したりできます。」と静かになる
- **文体ページ**: 同じ部品なので X・手作業が自動的に軽くなる。区切り線は既存の行罫線で足りるので足さない（任意項目は不採用）
- **不採用**: 軽い行を 1 行に畳む案（任意）。3 行を 1 行にすると note／Medium／X の名前が読めず必須 2 に反する
- **手作業の行**: 開閉させない（押せば即動く 2 本のリンクを軽くしただけ）。動作は不変

## 3. 手数の前後

| 経路 | 前 | 後 | 備考 |
| --- | --- | --- | --- |
| 取り込み: note をつないで文体を作る | 入力欄を押す → 入力 → Enter／つなぐ → 文体を作る = 4 手 | 行を押す（フォーカスが入力欄へ）→ 入力 → Enter／つなぐ → 文体を作る = 4 手 | 同数。判断は「4 欄のどれが必須か」→「一文を読む」に減る |
| 取り込み: X のアーカイブを選ぶ | 「tweets.js を選ぶ」→ ファイル選択 = 2 手 | 行を押す → 「tweets.js を選ぶ」→ ファイル選択 = 3 手 | +1。X は稀で、「返信も含める」を先に見せる必要があるため開閉を挟む |
| 文体ページ: 手作業で貼る | リンクを押す = 1 手 | 同じ = 1 手 | 不変 |
| 文体ページ: 外す | 外す → 確認 = 2 手 | 同じ | 不変 |

### 実装で決めたこと
- `voice.intake.leadEmpty` に「どれか一つ」を入れ、`voice.intake.more` を「あとから足したり外したりできます。」に。1 つつないだ後のリードは「文体は…書き方です。あとから足したり外したりできます。」と静かになる。新キーなし
- 取り込みが 1 件以上で成功した行は状態を `idle` に戻す（✓ の行が結果そのものなので「取り込みました。」は出さない）。0 件のときだけ「新しい文章はありませんでした。」を行の中に残す
- 手作業の行のクラスは `srcrow hand`（既存の汎用 `.manual` 規則と衝突するため `manual` を避けた）
- `npx tsc --noEmit` と `npm run build` は通過

### 残った懸念
- 軽い行 → 開く → 入力の流れは note／Medium では手数が増えないが、X は 1 手増える（上の表のとおり）
- 開いた行を閉じる手段は「名前を押す」と Esc の 2 つ。文体ページでは既存の `paste-add` の「やめる」と作法が少し違う
- 折り畳みの `▸` は文体ページの「詳細を見る」と同じ記号だが、行の名前が `--mute` のため「押せる」と気づくのはホバー時。初回の本人には十分と判断したが、実機で迷うなら名前をミント色にする選択肢がある
