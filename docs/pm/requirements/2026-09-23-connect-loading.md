# つないでいる間のローディング感

- 出所: 本人の言葉「つなぐを押して連携しているとき、もっとローディング感を強めてほしいです」（2026-09-23）
- 関係する決定: D-57（連携先を文体に紐づける）、D-59（段階表示は演出ではなく実態）、D-44、D-51

## 目的

つなぐを押してから 5〜10 秒、画面はほぼ変わらず、本人は「押せたのか、止まったのか」を確かめられません。待っている間ずっと「動いている・あとどれだけか」が見えるようにします。

## 利用者の状況

本人が取り込み画面または文体ページの材料の行で、note のアカウント名を入れて「つなぐ」を押します。裏では一覧を取り、記事を 1 本ずつ 250ms 空けて読むため 5〜10 秒かかります。いまの手がかりはヒント文が「取得中…」に変わることと、ボタンが押せなくなることだけで、どちらも目立たず、進み具合も終わりの見込みも分かりません。

## 必須

1. 「つなぐ」を押した行は、作業中ずっと **回るしるし（`.spinner`）＋ 状況の一文**を同じ行に出す。ヒント文の差し替えだけにしない。
2. 一文は動詞で終える、です・ます。note / Medium は「記事を読んでいます」、X は「アーカイブを読んでいます」。
3. 本数が分かっている間は一文に **「（n／m 本）」** を添え、n が増えるたびに更新する（D-59 の `voice.stage.readingN` と同じ型。ここでの数字は既に画面にある「n 件」と同種なので原則 2 に反しない）。本数が分からない段階・出所では数字を出さず一文だけにする。
4. 作業中の行は **畳めない**（Escape とトグルで閉じない）。入力欄とボタンは押せないまま、入れた文字は消さない。
5. 作業中も **箱の他の行は使える**（別の連携を開く・手作業で貼る・ファイルを選ぶ）。他の行が道連れで無効にならない。
6. 成功したら行は ✓ と件数の行に変わる（現状どおり）。新しい記事が無かったときは行を開いたまま「新しい文章はありませんでした。」を出す（現状どおり）。
7. 失敗したら回るしるしを消し、平易な一文と次の行動（もう一度つなぐ）を出す。入れたアカウント名は残す。
8. 作業中は状況の一文を `role="status"`（`aria-live="polite"`）で読み上げ、行そのものに `aria-busy="true"` を付ける。つなぐを押した時点でフォーカスは行の中に残る。
9. **最短 600ms** は回るしるしを出す。X のようにすぐ終わる取り込みでちらつかせない。
10. `prefers-reduced-motion` では回転を止め、しるしと一文は残す（`.spinner` の既存の扱いに合わせる）。

## 任意

- note の一覧を取っている間（本数が出る前）は「記事の一覧を見ています」を出し、本数が分かったら 3 の表示に切り替える。
- 15 秒を超えたら一文の下に「時間がかかっています。そのままお待ちください。」を薄く足す。

## やらないこと

- 進捗バー・パーセント・残り時間の表示。
- 取り込みの中止ボタン（文体の作成にはあるが、数秒の待ちには要らない）。
- 取り込んだ記事名を流していく表示。
- 箱の外（固定バーやサイドバー）への進捗の表示。

## 受け入れ条件

1. note をつないだとき、押した直後から終わるまで、行に回るしるしと状況の一文が出ている。
2. 記事を読んでいる間、「（n／m 本）」の n が増えていくのが見える。
3. 取り込み中に別の行（手作業）を開いて文章を貼れる。作業中の行は畳めない。
4. 存在しないアカウント名でつなぐと、しるしが消えて平易な一文が出て、入れた名前が欄に残っている。
5. X のアーカイブを選んだとき、しるしが一瞬ついて消えるちらつきが起きない。

## 本人に聞かずに決めた既定値

| 項目 | 決めた値 | 理由 |
| --- | --- | --- |
| 進捗の出し方 | note は実数（`import-progress` イベント）、Medium と X は数字なしの一文 | note は一覧の後に本数が確定する。Medium は 10 件固定の取得で刻みが出ない |
| 数字の単位 | 「n／m 本」 | 記事は「本」。既存の `voice.stage.readingN` と同じ言い回し |
| 最短表示 | 600ms | ちらつきの下限。これ以上長くすると速い取り込みが遅く感じる |
| 同時実行 | 妨げない（行ごとに独立） | 現在の実装が既にサービス単位。制限する理由がない |
| 置き場所 | 行の中（`.src-hint` の位置）。箱の高さは変えない | 行が動くとレイアウトが跳ねる |

## lita-ux への引き継ぎ

- 参考にする既存画面: `src/components/BuildingVoice.tsx` の段階表示と `.generating` / `.spinner`（`src/App.css:220-225`）。ただし取り込みは数秒なので**段階の一覧は作らない**。1 行に収める。
- 変える場所: `src/components/SourceBox.tsx` の `status()` と `RowState`（`working` に `done` / `total` を持たせる）。文言は `src/i18n/ja.ts` の `import.working` を置き換える形で足す（en も同数）。
- 行の高さを変えず、ミントは点（`#41c9b4`）にとどめる。原則 2・7・8・9 のまま。
- **調整役へ**: 必須 3 の実数には Rust 側が要ります。`src-tauri/src/lib.rs` の `import_note` から `import-progress`（`{ source, done, total }`）を出し、`crates/lita-sources/src/note.rs` の本文取得ループにコールバックを通す変更です（`voice-progress` と同じ形）。これが入るまでは数字なしの一文＋回るしるしで要件 1・2・4〜10 を満たせます。
